# guide — source and licence

The 40 rule files in this folder, and `_sections.md`, are an unmodified copy of the
`rules/` folder of the **nestjs-best-practices** agent skill (version 1.2.0).

- **Upstream:** https://github.com/Kadajett/agent-nestjs-skills — `skills/nestjs-best-practices/`
- **Author:** Kadajett — as declared in the skill's `SKILL.md`
- **Licence:** MIT — as declared in the skill's `SKILL.md` (`license: MIT`). On
  2026-10-11 the upstream repository carried no separate `LICENSE` file and the
  GitHub API reported no repository-level licence, so that declaration is the only
  licence text there is to reproduce.
- **Copied:** 2026-10-11, from upstream commit `3986e0c` (dated 2026-07-22).

Nothing here is written by the owner of this repository. The day-by-day plan in
`docs/` and the site code are separate work and only quote rule titles.

This is one author's rule set, not NestJS's official documentation, and it names no
NestJS version. Each rule ends with a `Reference:` link; what was checked about
those links, and when, is recorded in `docs/00-rules.md`, not here.

Do not edit these files. A rule that changes upstream is replaced by a fresh copy,
so the text on the site always matches the source.

`_template.md` from the source is left out — it is a placeholder, not a rule.
